# maxs-GPT-to-Albedo

**用 GPT 直接出 Albedo 图片。材质要求沿用 `maxs-SD-to-Albedo`，输入不要求已有雕刻贴图。**

## 共用标准与分流

执行前读取同插件的 [maxs-SD-to-Albedo](../maxs-SD-to-Albedo/SKILL.md)，沿用其中的材质与色彩、细节尺度、旧化、基色语义、假细节排除、有限迭代、平铺验收和导出要求。该技能是 Albedo 质量标准的维护来源；本技能改变输入和生成方式，不降低这些要求。

- **文字或外观参考 → 本技能。** GPT 设计材质布局并直接生成平面颜色贴图。照片、材质球和场景渲染只提供材料、配色和旧化参考。
- **已有 AO / Height / Normal，且要求对应 → SD 技能。** 先读取结构图，保留其 UV 布局；不以参考里的砖排或新生成结构替代。
- **已认可 Albedo 的后续调整 → 编辑该基准。** 沿用当前技能，但锁定布局、尺度、配色与未要求修改的细节。若须对应已有通道，回到 SD 技能检查。
- **只要 Midjourney 提示词 → `maxs-seamless-texture`。** 不把 GPT 生图请求转成 MJ 参数。

以上相邻技能随同一插件提供。如果仅复制本技能而缺少 SD 技能，先在当前安装中查找；找不到则说明共用标准缺失，不声称已完整加载。下述核心约束仍可用于交付，不杜撰缺失内容。

## 直接生成

1. **确定材料与覆盖范围。** 从当次请求和上下文提取材料、主次颜色、磨损程度、排列/密度、贴图代表的尺度、宽高比、目标尺寸与平铺需求。未指定时，重复地表/墙面可按正方形可平铺贴图推进，简述假设；不强制 decal、atlas 或独特表面平铺。已有足够信息就生成，只询问会改变材质方向的缺项。
2. **查看参考并说明角色。** 本地图片先查看。提取材料本色、颗粒和老化机制，不照搬渲染的阴影、曝光、镜头、球体、背景、文字或标识。暗场景参考不等于深黑 Albedo；亮高光不等于白色材质。
3. **写清平面贴图目标。** 满幅正交表面，无透视、景深、材质球、展示底板或文字。墙面正视、地面俯视，画面由材料铺满。用具体粒径、块体比例、材料分布描述尺度，不靠“AAA / 8K / 超细节”堆词。
4. **调用 GPT 图像生成。** Codex 优先内置 `image_gen`；其它客户端使用已可用的 GPT 生图能力及其实际工具说明。纯文字从零生成不附无关旧图；有参考时明确每张图的角色。只写提示词不算完成用户要求的图片。工具不可用时说明限制并给可复制提示词，不偷偷换模型、付费 API 或安装依赖来冒充直接生成。
5. **检查后再定基准。** 先看整体色彩、尺度和分布，再看原尺寸局部是否有假刻纹、糊面和光影。每次请求默认一版，必要时一次针对性纠错；两次仍无改善则说明具体不足并停止自行重抽。用户后续反馈再继续。获认可后以该版本编辑，避免每次重设计。

按需要读取 [GPT 提示词模板](references/prompt-templates.md)。模板服务当前材料，不把旧砖示例强加给石头、植物或其它材料。

## Albedo 的核心约束

- 中性配色指克制的饱和度、明度和冷暖关系，保留材料本色；默认不走艳橙、泛白、整片发黑的极端。用户明确的颜色要求优先。
- 大尺度色差、中尺度磨损与小尺度颗粒有层次，局部留安静区域。增加细节不等于叠满裂纹、白点、蚯蚓纹、指纹旋涡或蜂窝花边。
- 污垢遵循材料与位置，增加脏度时小幅改覆盖或强度，保留干净与旧化区域的对比。去假纹理不抹掉真实颗粒和材料变化。
- 只表达本色：无烘焙 AO、投影、方向性明暗、高光、亮倒角或全图照明渐变。真实沉积可以改变颜色，不能拿阴影冒充积垢。
- “ArtStation / AAA”是视觉目标，不是已认证结果。不存在源结构图时，不声称与旧 Normal / AO 对齐；后续通道需从已认可布局制作并另验。

## 无缝与细节验收

需要平铺时，检查无间隔的 **2×2 重复、宽高各半的循环偏移、四角交汇和原尺寸局部**。同时检查几何连续、跨边界材质颜色、颗粒尺度和显眼图案重复。提示词写 seamless、边缘 RGB 相等或把图片放大，都不能证明无缝。

颜色缝与几何缝分开处理：几何不连续需在接缝视图中重建对应结构；仅颜色断层才参考 SD 技能的 [已验证校色流程](../maxs-SD-to-Albedo/references/seam-repair.md)。沿用已授权的处理方式并服从当前客户端图像编辑工具约束，不把这份技能当作绕过工具限制的授权。程序化校色可复用其 [脚本](../maxs-SD-to-Albedo/scripts/seam_color.py)，新图必须重新选区，不能套旧砖案例坐标。

一旦修改接缝，再检查两轴、四角和细节，防止出现模糊十字、残余色块或轮廓漂移。检查工具不可用时明确标注“未做平铺检查”，不将候选图称为最终无缝贴图。

## 导出与范围

- 默认只交付 Albedo，不附送 Normal / ORM / Roughness。用户追加通道时，参照 SD 技能的按需流程；不简单灰度化基色冒充 Roughness。
- 保存 GPT 原始输出、所用提示词和目标尺寸导出，保留已认可版本。读取实际尺寸和通道，区分原生输出、插值放大和 AI 重建；不承诺未经核验的原生 4K。
- Albedo 通常交付 RGB PNG，作为 sRGB 颜色读取；数据通道另外按线性读取。导出到用户位置或项目目录，避免仅留下提示词或临时预览。
- 回复给图片、文件位置、实测尺寸和主要未验证项。未在引擎验证时，不宣称整套 PBR 或 AAA 成品通过。

本技能复用 SD 技能中已有的真实质量反馈与接缝修复经验；GPT 从零生成的模板是工作模板，尚无本技能独立实测认可案例。
