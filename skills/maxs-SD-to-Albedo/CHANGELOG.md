# Changelog

## [1.1.0] - 2026-10-05

- 补充用户最终认可的颜色接缝 v2：先整体边缘校色，再局部修正四角砖内部色调。
- 新增可复用 RGB8 校色脚本、专属案例遮罩与测试，保护源文件和选区外像素。
- 强制区分边界像素相等与视觉连续，交付半幅偏移、四角局部和 2×2 检查。
- 标明早期认可图仍有色缝，不再混同最终修复版；记录窄条 inpaint 失败。

## [1.0.1] - 2026-10-05

- 按用户指定更名为 `maxs-SD-to-Albedo`，同步目录、调用名和文档引用。

## [1.0.0] - 2026-10-05

- 新增已有雕刻贴图转写实 Albedo 的图生图流程，区分结构输入与材质参考。
- 沉淀用户认可的中性色旧砖案例、有效提示词与失败纠正。
- 增加按需 Roughness 推断、实际数值检查和线性数据说明。
- 明确生成式对齐、无缝平铺、原生分辨率与 AAA 引擎验收的证据边界。
